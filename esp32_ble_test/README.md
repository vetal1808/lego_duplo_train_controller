# Пульт для поезда LEGO DUPLO на ESP32

Плата LOLIN32 Lite сама находит поезд по Bluetooth и подключается к нему, а потом управляет им с ручки и кнопок. Команды запускаются из папки `esp32_ble_test`, порт — тот, под которым видна плата (сейчас COM4, раньше бывал COM9).

Проверка кнопок и сна после перепайки (интерактивная, скрипт просит нажимать кнопки):

```bash
~/.platformio/penv/Scripts/python.exe tools/button_sleep_test.py --port COM4
```

## Управление

| Орган | Действие |
|---|---|
| Ручка (потенциометр) | Скорость и направление. Около середины — стоп, дальше 10–100% с шагом 10 |
| Кнопка 1 | Стоп. Поезд не поедет, пока ручку не вернуть в середину |
| Кнопка 2 | Гудок |
| Кнопка 3 | Следующий цвет фары |
| Кнопка 4 | Резерв, ничего не делает |

Назначения кнопок, мёртвая зона и шаг скорости меняются в [src/config.h](src/config.h).

## Светодиод на плате

| Светодиод | Состояние |
|---|---|
| Часто мигает | Ищет поезд или подключается |
| Горит постоянно | Подключён к поезду |
| Короткие вспышки раз в секунду, 3 с | Засыпает; любая кнопка ещё может его остановить |
| Не горит | Deep sleep, разбудить кнопкой 2 |

## Безопасность

- **Блокировка хода:** после каждого подключения поезд получает стоп и не поедет, пока ручка не побывает в середине. Иначе при переподключении с повёрнутой ручкой он резко стартует.
- **Поднятый поезд** сам останавливает мотор, если колёса крутятся в воздухе. Это поведение хаба; чтобы поехать снова, поставь поезд и сдвинь ручку.
- **Неактивность 5 минут** (ни кнопок, ни движения ручки): стоп, отключение от поезда, плата засыпает.
- **Сон:** если поезд не найден за 2 минуты (или потерян и не найден за 1 минуту), плата тоже засыпает.

## Сон

Через 3 с после перехода в `SLEEP` плата уходит в deep sleep: процессор и Bluetooth выключены, работает только RTC-домен.

- **Будит только кнопка 2** (`WAKE_BUTTON` в [src/config.h](src/config.h)). У кнопок 1 и 3 пины не RTC, во сне они не читаются.
- Во сне земля кнопки 2 (GPIO 15) удерживается в LOW, кнопка (GPIO 2) подтянута вверх встроенным резистором. Потенциометр обесточен.
- После пробуждения прошивка стартует с нуля (~1 с) и ищет поезд. В логе: `woke from deep sleep by button 2`. Гудок при этом не звучит.
- Пока кнопка 2 зажата, плата не засыпает.

### Как проверить ток сна вольтметром

Резистор 1 кОм в плюсовой провод батарейки, параллельно ему перемычка. Включить с перемычкой, дождаться сна (`z` по UART или 2 минуты без поезда), снять перемычку и измерить напряжение на резисторе: ток = мВ / 1 кОм, то есть 100 мВ = 100 мкА. Около 1 В и больше или перезагрузки — плата не спит. Перед нажатием кнопки 2 перемычку вернуть.

## Сборка и прошивка

```bash
~/.platformio/penv/Scripts/pio.exe run -e lolin32_lite -t upload --upload-port COM9
```

## Лог

```bash
~/.platformio/penv/Scripts/pio.exe device monitor -p COM9 -b 115200 --filter log2file
```

Что смотреть:

| Строка | Значение |
|---|---|
| `[FSM] ... -> CONNECTED` | Поезд подключён и отвечает |
| `[UI] button N pressed` | Нажата кнопка |
| `[UI] speed request X% (knob Y)` | Скорость с ручки; `knob` — сырое значение ручки, примерно от −100 до 100 |
| `[UI] connected: return the knob to zero` | Блокировка хода после подключения |
| `tx speed X%` / `tx stop` | Команда ушла поезду |
| `speed sensor: X` | Скорость, которую измерил поезд |
| `[HB] ... max_gap=...` | Раз в 5 с: самая долгая пауза цикла пульта, норма — меньше 30000 us |

### Команды по UART

| Команда | Действие |
|---|---|
| `s` | Статус и счётчики |
| `0` | Стоп, как кнопка 1 |
| `h` | Гудок |
| `c` | Следующий цвет фары |
| `d` | Разорвать связь (проверка переподключения) |
| `w` | Отменить засыпание (в течение 3 с после `SLEEP`) |
| `z` | Уснуть сейчас: стоп, отключение, deep sleep |
| `f` | Подключиться к несуществующему адресу (проверка, что пульт не блокируется) |

## Особенности хаба

Поезд берёт новый случайный адрес при каждом включении (`type=1`), поэтому плата узнаёт его по сервису LEGO, а не по адресу. Найдя первый поезд, плата ещё 1 с слушает эфир и подключается к поезду с самым сильным сигналом, то есть к ближайшему. В логе: `train ... looking for a nearer one` и `nearest train by service, rssi=...`.

Процессор работает на 80 МГц вместо 240: это минимум, при котором работает Bluetooth.

## Проверка без поезда

Поезд должен быть выключен, монитор порта закрыт. Занимает около 2,5 минут, в конце плата спит.

```bash
~/.platformio/penv/Scripts/python.exe tools/no_train_test.py --port COM9
```

## Если не подключается

Пришли файл лога. На что смотреть:

- **Поезда нет среди строк `dev`:** поезд не рекламирует себя или фильтр его не узнаёт.
- **`step N/4 ... FAILED rc=...`:** сбой на этом шаге, рядом код ошибки.
- **`no notification`:** подписка прошла, но хаб молчит.
- **`disconnected: reason=...` сразу после подключения:** хаб сам разорвал связь, причина в коде.
